# hissa-landing-page

Uzcard Hissa BNPL (Buy Now Pay Later) xizmati uchun rasmiy landing page veb-sayti.

## Texnologiyalar

- React 19
- TypeScript
- Vite
- Tailwind CSS v4
- Leaflet
- Lucide React
- Canvas Confetti

## Loyihani o'rnatish va ishga tushirish

1. Qaramliklarni o'rnatish:
```bash
npm install
```

2. Lokal serverni ishga tushirish:
```bash
npm run dev
```

3. Loyihani ishlab chiqarish (production) uchun yig'ish:
```bash
npm run build
```
